# コンポーネント デザインルール

## コンポーネント設計の原則

### 1. セマンティックトークンを使う

コンポーネントのスタイルには、必ずセマンティックカラー（用途別カラー）を使います。`#2563eb` のような色コードや `blue.600` のようなプリミティブカラーを直接書かないでください。

```
良い例: var(--color-primary-default)
悪い例: #2563eb
```

（このコードは「CSS変数を通じてセマンティックカラーを参照する」ことを意味します。こうすることで、テーマ変更時に自動で色が切り替わります）

### 2. バリアントで意味を伝える

コンポーネントの見た目の違いは `variant` プロパティで制御します。色をカスタムで指定するのではなく、用意されたバリアントから選びます。

### 3. アクセシビリティは必須

- すべてのインタラクティブ要素にフォーカスリングを付ける
- `aria-*` 属性で状態を補足する
- 色だけに頼らず、テキストやアイコンでも情報を伝える

### 4. 状態を明示する

すべてのインタラクティブコンポーネントは以下の状態を持ちます:

| 状態 | 説明 | 視覚的な表現 |
|---|---|---|
| **default** | 通常状態 | 標準のスタイル |
| **hover** | マウスオーバー | 背景色が少し濃くなる |
| **active** | クリック中 | さらに濃くなる |
| **focus** | キーボードフォーカス | 青いフォーカスリング（2px） |
| **disabled** | 無効状態 | 透明度50%、操作不可カーソル |
| **loading** | 読み込み中 | スピナー表示、操作不可 |

## Button（ボタン）

### 概要

ユーザーがアクションを実行するための主要なインタラクティブ要素です。

### バリアント

| バリアント | 用途 | 背景色 | 文字色 | 特徴 |
|---|---|---|---|---|
| `primary` | 主要なアクション（保存、送信） | 青（`primary.default`） | 白 | 画面内で最も目立つボタン |
| `secondary` | 補助的なアクション（キャンセル、戻る） | 白（`background.default`） | 黒（`foreground.default`） | ボーダーあり |
| `ghost` | 控えめなアクション（もっと見る） | 透明 | 黒（`foreground.default`） | ボーダーなし |
| `destructive` | 危険なアクション（削除、リセット） | 赤（`error.default`） | 白 | 赤で注意を促す |
| `ai` | AI関連アクション（生成、要約） | 紫（`ai.default`） | 白 | 紫のグロウエフェクト付き |

### サイズ

| サイズ | 高さ | 横パディング | フォントサイズ | アイコンとの間隔 | 用途 |
|---|---|---|---|---|---|
| `sm` | 32px（h-8） | 12px（px-3） | 14px（text-sm） | 6px | テーブル内、狭いスペース |
| `md` | 40px（h-10） | 16px（px-4） | 16px（text-base） | 8px | 標準（デフォルト） |
| `lg` | 48px（h-12） | 24px（px-6） | 18px（text-lg） | 10px | ヒーロー、目立たせたい場所 |

### 状態の詳細

| 状態 | primary | secondary | ghost | destructive | ai |
|---|---|---|---|---|---|
| **default** | 青背景 | 白背景+ボーダー | 透明 | 赤背景 | 紫背景+グロウ |
| **hover** | 濃い青 | 薄いグレー背景 | 薄いグレー背景 | 透明度90% | 透明度90% |
| **active** | さらに濃い青 | - | - | - | - |
| **disabled** | 透明度50% | 透明度50% | 透明度50% | 透明度50% | 透明度50% |
| **loading** | スピナー表示 | スピナー表示 | スピナー表示 | スピナー表示 | スピナー表示 |

### 共通スタイル

- 角丸: `borderRadius.md`（6px）
- トランジション: 150ms
- フォーカスリング: 青、2px、offset 2px
- disabled時: `opacity: 0.5`, `cursor: not-allowed`
- loading時: ボタンはdisabledになり、左アイコンの代わりにスピナーが表示される

### アイコン付きボタン

- `leftIcon`: テキストの左にアイコンを配置（loading時はスピナーに置き換わる）
- `rightIcon`: テキストの右にアイコンを配置（loading時も表示される）
- アイコンは `shrink-0`（縮小しない）が設定される

## Badge（バッジ）

### 概要

ステータス、カテゴリ、メタデータなどの短いラベルを表示する小さなコンポーネントです。

### バリアント

| バリアント | 用途 | 背景色 | 文字色 |
|---|---|---|---|
| `default` | 一般的なラベル | 薄いグレー（`background.muted`） | グレー（`foreground.subtle`） |
| `success` | 完了、有効、正常 | 薄い緑（`success.subtle`） | 緑（`success.default`） |
| `error` | エラー、無効、異常 | 薄い赤（`error.subtle`） | 赤（`error.default`） |
| `warning` | 注意、保留 | 薄い黄（`warning.subtle`） | 黄（`warning.default`） |
| `ai` | AI生成、AI関連 | 薄い紫（`ai.subtle`） | 紫（`ai.default`） |
| `outline` | 控えめなラベル | 透明（ボーダーのみ） | グレー（`foreground.subtle`） |

### サイズ・スタイル

Badge は単一サイズです:

| プロパティ | 値 |
|---|---|
| パディング | 横8px、縦2px（`px-2 py-0.5`） |
| フォントサイズ | 12px（`text-xs`） |
| フォントウェイト | medium（500） |
| 角丸 | `borderRadius.full`（完全な丸み） |
| 内部の間隔 | 4px（`gap-1`）-- アイコンとテキストの間 |

## Input（テキスト入力）

### 概要

ユーザーがテキストを入力するためのフォーム要素です。ラベル、エラーメッセージ、ヒントテキストを組み合わせて使います。

### 構造

Input コンポーネントは以下の要素で構成されます:

```
[ラベル]          ... 省略可能
[       入力欄       ]  ... 左右にアドオン配置可能
[ヒント or エラー]  ... 省略可能、エラーが優先
```

（この図は「Input コンポーネントがラベル・入力欄・補助テキストの3層構造になっている」ことを意味します）

### サイズ・スタイル

| プロパティ | 値 |
|---|---|
| 高さ | 40px（`h-10`） |
| パディング | 横12px、縦8px（`px-3 py-2`） |
| フォントサイズ | 14px（`text-sm`） |
| 角丸 | `borderRadius.md`（6px） |
| ボーダー | `border.default`（1px） |
| 背景色 | `background.default`（白） |

### ラベル

| プロパティ | 値 |
|---|---|
| フォントサイズ | 14px（`text-sm`） |
| フォントウェイト | medium（500） |
| 色 | `foreground.default` |
| ラベルと入力欄の間隔 | 6px（`gap-1.5`） |

### 状態の詳細

| 状態 | ボーダー | その他 |
|---|---|---|
| **default** | グレー（`border.default`） | - |
| **hover** | - | トランジション 150ms |
| **focus** | 透明（非表示） | 青のフォーカスリング（2px、offset なし） |
| **disabled** | グレー | 透明度50%、操作不可カーソル |
| **error** | 赤（`error.default`） | フォーカスリングも赤に変化 |

### プレースホルダー

- 色: `foreground.muted`（中間グレー）
- ユーザーに入力例や期待する形式を伝える

### アドオン（左右の装飾要素）

- `leftAddon`: 入力欄の左端にアイコンなどを配置（検索アイコンなど）
- `rightAddon`: 入力欄の右端にアイコンなどを配置（クリアボタンなど）
- アドオンがある場合、入力テキストのパディングが自動的に広がる（`pl-10` / `pr-10`）
- アドオンの色: `foreground.subtle`

### エラーとヒント

- **エラーメッセージ**: 赤文字（`error.default`）、12px（`text-xs`）
- **ヒントテキスト**: グレー文字（`foreground.subtle`）、12px（`text-xs`）
- エラーとヒントが両方ある場合、**エラーが優先して表示**される
- `aria-invalid` 属性が自動で設定される
- `aria-describedby` でエラー/ヒントとの関連付けが自動で行われる

## AI バリアントのガイドライン

### いつ使うか

`variant="ai"` は以下の場合に使用します:

| 使うべき場面 | 例 |
|---|---|
| AIがアクションを実行するボタン | 「AIで生成」「要約する」「翻訳する」 |
| AIが生成したコンテンツのラベル | AI生成テキストの横の Badge |
| AIが推薦・提案した要素 | AIおすすめの Badge |

### 使わない場面

| 使わない場面 | 理由 |
|---|---|
| 通常のCRUD操作 | AI が関与していないため |
| AIの設定画面のボタン | 設定そのものはAIアクションではない |
| すべての要素をAIバリアントにする | 特別感が薄れ、区別の意味がなくなる |

### なぜ紫か

紫色をAIの色として採用した理由:

1. **意味的な区別**: 青（プライマリ）= 人間のアクション、紫（AI）= AIのアクション、と明確に分けられる
2. **視覚的な近さ**: 紫は青の隣接色であり、UIに馴染みながらも区別がつく
3. **連想**: 紫は「知性」「創造性」「先進性」を想起させ、AIのイメージに合致する
4. **既存色との衝突なし**: 赤（エラー）、緑（成功）、黄（警告）は既に意味を持つため使えない

### AI バリアントの視覚的特徴

- **背景色**: `ai.default`（`#9333ea`）-- 鮮やかな紫
- **文字色**: `ai.foreground`（`#ffffff`）-- 白
- **Badge の場合**: 薄い紫背景（`ai.subtle`）に紫文字（`ai.default`）
- **Button の場合**: グロウエフェクト（`shadow: 0 0 12px`）で「光っている」ような演出

## 新しいコンポーネントを追加するときのチェックリスト

新しいコンポーネントを設計・実装する際は、以下のすべてを確認してください。

### デザイン段階

- [ ] **必要性の確認**: 既存コンポーネントの組み合わせで実現できないか検討したか
- [ ] **用途の定義**: どの画面で、どのような目的で使われるかを明文化したか
- [ ] **バリアント設計**: 必要なバリアントを洗い出したか（AI バリアントが必要かも検討）
- [ ] **サイズ設計**: sm / md / lg のサイズが必要か検討したか
- [ ] **状態設計**: default / hover / active / focus / disabled / loading を定義したか

### トークンの使用

- [ ] **セマンティックカラー**: プリミティブカラーではなくセマンティックカラーを使っているか
- [ ] **スペーシング**: トークンに定義された値を使っているか（独自の値を使っていないか）
- [ ] **タイポグラフィ**: 定義済みのフォントサイズ・ウェイトを使っているか
- [ ] **角丸**: `borderRadius` トークンの値を使っているか
- [ ] **シャドウ**: `shadows` トークンの値を使っているか

### アクセシビリティ

- [ ] **フォーカスリング**: キーボード操作時にフォーカスリングが表示されるか
- [ ] **aria 属性**: 必要な `aria-*` 属性を設定しているか
- [ ] **色以外の手段**: 色だけに頼らず、テキストやアイコンでも情報を伝えているか
- [ ] **コントラスト比**: テキストと背景のコントラスト比が WCAG AA 基準（4.5:1 以上）を満たすか

### 実装

- [ ] **TypeScript 型**: Props の型定義を作成したか
- [ ] **デフォルト値**: 適切なデフォルトの variant と size を設定したか
- [ ] **className の拡張**: 外部から `className` を渡してスタイルを拡張できるか
- [ ] **`@ai-component` タグ**: コンポーネントの JSDoc に `@ai-component` タグを付けたか

### ドキュメント

- [ ] **このファイルへの追記**: 新コンポーネントの仕様をこのドキュメントに追記したか
- [ ] **使用例**: 代表的な使用パターンを記載したか
